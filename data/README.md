# Data Directory

This directory contains all datasets used in the skincare recommendation system project.

## Structure
- `raw/`: Original, unmodified datasets collected from public or third-party sources.
- `processed/`: Cleaned and preprocessed datasets generated during analysis.

## Notes
- Raw data files should not be manually edited.
- Processed datasets are generated through preprocessing scripts or notebooks.
- Dataset details and sources will be documented as they are finalized.
